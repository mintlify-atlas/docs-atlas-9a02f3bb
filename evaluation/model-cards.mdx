## Shared architecture and training configuration

All four checkpoints use identical architecture (`SuperEnhancedTemporalModel`) and training hyperparameters. They differ only in training trajectory (random seed / convergence behavior).

### Architecture

| Parameter | Value |
|---|---|
| Model class | `SuperEnhancedTemporalModel` |
| `feature_dim` | 1280 |
| `hidden_dim` | 768 |
| `num_classes` | 4 |
| `num_lstm_layers` | 4 |
| `num_attention_heads` | 12 |
| `dropout` | 0.4 |
| `bidirectional` | `True` |

### Training configuration

| Parameter | Value |
|---|---|
| Learning rate | 0.001 |
| Batch size | 48 |
| Max epochs | 150 |
| Early stopping patience | 25 |

### Hardware and software

| Component | Detail |
|---|---|
| GPU | NVIDIA A100 MIG (9.8 GB VRAM) |
| CUDA | 11.8 |
| cuDNN | Enabled |
| Framework | PyTorch |
| Vision | Torchvision |
| Video decode | OpenCV |
| Numerics | NumPy, Pandas |
| Metrics | scikit-learn |
| Feature storage | h5py |
