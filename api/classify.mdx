## Endpoint

```
POST /api/classify
```

Classifies a dataset video using the four-checkpoint ensemble (`best_ensemble_model_1.pt` through `best_ensemble_model_4.pt`). Returns the predicted category, confidence score, per-class scores, and a per-model breakdown.

<Note>
Only videos present in the dataset are supported. The classifier loads pre-extracted HDF5 features from `features_enhanced/test_features_multiscale.h5`. Uploading external video files is not supported.
</Note>

## Request

Content-Type: `multipart/form-data`

<ParamField body="selected_video" type="string" required>
  Filename of the video to classify, exactly as returned by [GET /api/videos](/api/videos). Example: `minecraft_clip_001.mp4`.
</ParamField>

<ParamField body="use_tta" type="string" default="false">
  Set to `"true"` to enable Test-Time Augmentation. TTA runs inference across four temporal augmentation modes (original, reversed, speed-up, speed-down) and averages the resulting probability distributions. Increases accuracy at the cost of ~4× inference time.
</ParamField>

## Response

<ResponseField name="success" type="boolean" required>
  `true` on success, `false` on error.
</ResponseField>

<ResponseField name="result" type="object">
  Classification result. Present only when `success` is `true`.

  <Expandable title="properties" defaultOpen={true}>
    <ResponseField name="category" type="string" required>
      Predicted content category. One of: `Animation`, `Flat_Content`, `Gaming`, `Natural_Content`.
    </ResponseField>

    <ResponseField name="confidence" type="number" required>
      Confidence for the predicted class, as a percentage (0–100).
    </ResponseField>

    <ResponseField name="video_name" type="string" required>
      The `selected_video` value echoed back.
    </ResponseField>

    <ResponseField name="all_scores" type="object" required>
      Ensemble probability for every class, as percentages.

      <Expandable title="properties">
        <ResponseField name="Animation" type="number">
          Ensemble score for Animation (%).
        </ResponseField>
        <ResponseField name="Flat_Content" type="number">
          Ensemble score for Flat\_Content (%).
        </ResponseField>
        <ResponseField name="Gaming" type="number">
          Ensemble score for Gaming (%).
        </ResponseField>
        <ResponseField name="Natural_Content" type="number">
          Ensemble score for Natural\_Content (%).
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="model_scores" type="object[]" required>
      Per-model breakdown — one entry per ensemble checkpoint.

      <Expandable title="properties">
        <ResponseField name="model" type="string">
          Checkpoint filename, e.g. `best_ensemble_model_2.pt`.
        </ResponseField>
        <ResponseField name="confidence" type="number">
          This model's top-class confidence as a percentage.
        </ResponseField>
        <ResponseField name="probs" type="number[]">
          Softmax probabilities for all four classes as percentages. Order matches the category mapping: `[Animation, Flat_Content, Gaming, Natural_Content]`.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error responses

### 400 — no video provided

```json
{
  "success": false,
  "error": "No selected_video provided"
}
```

### 400 — video not found in dataset

```json
{
  "success": false,
  "error": "Selected video not found in dataset"
}
```

### 500 — classifier or loader initialization failed

Returned if the model checkpoints cannot be loaded (e.g., files missing from `models_enhanced/`):

```json
{
  "success": false,
  "error": "No checkpoints found in /path/to/models_enhanced. Expected: ['best_ensemble_model_1.pt', ...]",
  "trace": "Traceback (most recent call last): ..."
}
```

## Examples

<CodeGroup>

```bash Standard inference
curl -X POST http://localhost:5000/api/classify \
  -F "selected_video=minecraft_clip_001.mp4"
```

```bash With TTA
curl -X POST http://localhost:5000/api/classify \
  -F "selected_video=minecraft_clip_001.mp4" \
  -F "use_tta=true"
```

```python Python
import requests

# Standard inference
response = requests.post(
    "http://localhost:5000/api/classify",
    data={"selected_video": "minecraft_clip_001.mp4"}
)
result = response.json()

if result["success"]:
    r = result["result"]
    print(f"Category: {r['category']}")
    print(f"Confidence: {r['confidence']:.1f}%")
    for m in r["model_scores"]:
        print(f"  {m['model']}: {m['confidence']:.1f}%")
else:
    print("Error:", result["error"])

# With TTA
response_tta = requests.post(
    "http://localhost:5000/api/classify",
    data={"selected_video": "minecraft_clip_001.mp4", "use_tta": "true"}
)
```

</CodeGroup>

## Per-model scores breakdown

The `model_scores` array contains one entry per ensemble checkpoint in the order they were loaded:

1. `best_ensemble_model_1.pt`
2. `best_ensemble_model_2.pt`
3. `best_ensemble_model_3.pt`
4. `best_ensemble_model_4.pt`

Each entry's `probs` array is ordered to match the category index mapping: `[Animation, Flat_Content, Gaming, Natural_Content]`. Values are softmax probabilities scaled to percentages and will sum to approximately 100.

The top-level `all_scores` and `confidence` fields reflect the **ensemble average** across all four models — not any single model's output.
