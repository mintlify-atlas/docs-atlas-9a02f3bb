## Prerequisites

Before you begin, make sure you have the following installed:

- **Python 3.8+**
- **CUDA-capable GPU** (recommended; CPU fallback is supported)
- **PyTorch** with matching CUDA version
- **OpenCV** (`opencv-python`)
- **Flask**
- **h5py**

<Note>
  The system automatically falls back to CPU if CUDA is unavailable. Set `device='cpu'` in `SingleVideoClassifier` or let the app detect it at startup — `app.py` calls `torch.cuda.is_available()` before selecting the device.
</Note>

## Setup

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/itsmanask/NVIDIA-Video-Classification-Project.git
    cd NVIDIA-Video-Classification-Project
    ```
  </Step>

  <Step title="Install dependencies">
    Install all required packages. The core runtime dependencies are:

    ```bash
    pip install torch torchvision flask opencv-python h5py numpy pandas scikit-learn tqdm psutil matplotlib seaborn requests
    ```

    <CodeGroup>
      ```bash pip (one-liner)
      pip install torch torchvision flask opencv-python h5py numpy pandas scikit-learn tqdm psutil matplotlib seaborn requests
      ```

      ```bash pip (multiline)
      pip install torch \
          torchvision \
          flask \
          opencv-python \
          h5py \
          numpy \
          pandas \
          scikit-learn \
          tqdm \
          psutil \
          matplotlib \
          seaborn \
          requests
      ```
    </CodeGroup>

    For GPU support, install PyTorch with the CUDA variant matching your driver. See [pytorch.org/get-started](https://pytorch.org/get-started/locally/) for the correct install command.
  </Step>

  <Step title="Prepare model checkpoints">
    The inference server loads a 4-model ensemble. Place the following checkpoint files inside a `models_enhanced/` directory next to `app.py`:

    ```
    Flask Local New/
    ├── app.py
    ├── models_enhanced/
    │   ├── best_ensemble_model_1.pt
    │   ├── best_ensemble_model_2.pt
    │   ├── best_ensemble_model_3.pt
    │   └── best_ensemble_model_4.pt
    ```

    Each `.pt` file is a PyTorch checkpoint produced during training. The app loads all four in `SELECTED_CHECKPOINTS` and averages their softmax outputs at inference time.

    If the `models_enhanced/` directory does not exist next to `app.py`, the server also checks `/mnt/data/models_enhanced` and `D:/models_enhanced` as fallbacks.
  </Step>

  <Step title="Prepare feature files">
    The server reads pre-extracted features from an HDF5 file rather than processing raw video at request time. Place the feature file in a `features_enhanced/` directory next to `app.py`:

    ```
    Flask Local New/
    ├── app.py
    ├── features_enhanced/
    │   └── test_features_multiscale.h5
    ```

    The HDF5 file is expected to contain:

    | Key | Shape | Description |
    |---|---|---|
    | `features` | `[N, max_frames, feature_dim]` | Per-frame CNN feature vectors |
    | `labels` | `[N]` | Integer class labels |
    | `num_frames` | `[N]` | Valid frame count for each video |

    Key parameters: `feature_dim=1280`, `max_frames=73`.

    The `SingleVideoFeatureLoader` scans for any file matching `test_features*.h5` inside `features_enhanced/`, so the exact filename can vary as long as it matches that glob.
  </Step>

  <Step title="Start the Flask server">
    From the `Flask Local New/` directory, run:

    ```bash
    python app.py
    ```

    On startup, the server prints the resolved paths and begins listening on port 5000:

    ```
    Index HTML path: /path/to/Flask Local New/index.html
    User script path: /path/to/Flask Local New/test_already_extracted.py
    Features dir: /path/to/Flask Local New/features_enhanced
    Models dir: /path/to/Flask Local New/models_enhanced
    Processed test dir: /path/to/Flask Local New/data/processed/test
     * Running on http://0.0.0.0:5000
    ```
  </Step>

  <Step title="Open the web UI and classify a video">
    Open your browser and navigate to:

    ```
    http://localhost:5000
    ```

    The web UI lists all available test videos grouped by category. Select a video and click **Classify** to run inference. The response includes:

    - Predicted category (Animation, Flat\_Content, Gaming, or Natural\_Content)
    - Confidence score (%)
    - Per-model breakdown across all four ensemble models
    - All-class probability scores
  </Step>
</Steps>

## Classify a video via the API

You can also call the `/api/classify` endpoint directly with `curl` or any HTTP client.

**List available videos first:**

```bash
curl http://localhost:5000/api/videos
```

**Classify a specific video (standard inference):**

```bash
curl -X POST http://localhost:5000/api/classify \
  -F "selected_video=your_video_filename.mp4" \
  -F "use_tta=false"
```

**Classify with Test-Time Augmentation enabled:**

```bash
curl -X POST http://localhost:5000/api/classify \
  -F "selected_video=your_video_filename.mp4" \
  -F "use_tta=true"
```

A successful response looks like:

```json
{
  "success": true,
  "result": {
    "category": "Gaming",
    "confidence": 97.43,
    "video_name": "your_video_filename.mp4",
    "all_scores": {
      "Animation": 0.21,
      "Flat_Content": 0.84,
      "Gaming": 97.43,
      "Natural_Content": 1.52
    },
    "model_scores": [
      { "model": "best_ensemble_model_1.pt", "confidence": 96.11, "probs": [0.18, 0.91, 96.11, 2.80] },
      { "model": "best_ensemble_model_2.pt", "confidence": 98.02, "probs": [0.25, 0.61, 98.02, 1.12] },
      { "model": "best_ensemble_model_3.pt", "confidence": 97.89, "probs": [0.19, 0.77, 97.89, 1.15] },
      { "model": "best_ensemble_model_4.pt", "confidence": 97.70, "probs": [0.22, 1.07, 97.70, 1.01] }
    ]
  }
}
```

<Note>
  The `/api/classify` endpoint only accepts videos that are already indexed in the HDF5 feature file. It does not accept raw video uploads or external URLs through the API — those are handled by the `test_already_extracted.py` script's interactive CLI mode.
</Note>
