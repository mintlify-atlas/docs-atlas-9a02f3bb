title: "Model ensemble"
description: "Build a 5-model ensemble to improve accuracy from ~92% to ~95%"
---

The production system uses a **4-checkpoint ensemble** (selected from 5 trained
models) that averages softmax probabilities across models at inference time.
Ensembling lifts accuracy from individual model peaks of ~92 % toward the
>95 % target.

## Ensemble strategy

Five independent `SuperEnhancedTemporalModel` instances are trained with
identical hyperparameters but different random seeds:

```python
for i in range(num_models):
    torch.manual_seed(42 + i)
    np.random.seed(42 + i)
    random.seed(42 + i)
    model, results = trainer.train_single_model(
        model_name=f'ensemble_model_{i}',
        ...)
```

Different seeds produce different weight initialisations and different data
ordering, which diversifies the errors each model makes — the key requirement
for effective ensembling.

| `best_ensemble_model_2.pt` | 43 | 92.13 % | 92.15 % |
| `best_ensemble_model_3.pt` | 42 | 91.86 % | 91.87 % |
| `best_ensemble_model_4.pt` | 40 | 91.86 % | 91.88 % |

### Per-class F1 scores (%)

| Checkpoint | Animation | Flat\_Content | Gaming | Natural\_Content |
|---|---|---|---|---|
| `best_ensemble_model_1.pt` | 1.10 | 93.47 | 66.06 | 96.69 |
| `best_ensemble_model_2.pt` | 86.46 | 96.74 | 87.88 | 97.52 |
| `best_ensemble_model_3.pt` | 87.67 | 95.47 | 88.00 | 96.38 |
| `best_ensemble_model_4.pt` | 88.02 | 95.24 | 88.48 | 95.77 |

<Note>
  Model 1 has substantially lower overall accuracy (72.73 %) and near-zero F1
  on the Animation class. Despite this, it is retained in the ensemble because
  its error distribution differs from models 2–4: it is strong on
  Flat\_Content and Natural\_Content, and those correct predictions reinforce
  the majority vote while its Animation errors are outvoted 3-to-1 by the
  other models. Diversity in the ensemble outweighs individual weakness.
</Note>

## Selected checkpoints in production

The Flask app (`app.py`) declares the four checkpoints used at inference time:

```python
# app.py
SELECTED_CHECKPOINTS = [
    "best_ensemble_model_1.pt",
    "best_ensemble_model_2.pt",
    "best_ensemble_model_3.pt",
    "best_ensemble_model_4.pt",
]
```

At startup the app resolves each name against `MODELS_DIR` and passes the
resolved paths to `SingleVideoClassifier`:

```python
paths = [str(MODELS_DIR / name) for name in SELECTED_CHECKPOINTS if (MODELS_DIR / name).exists()]
classifier = SingleVideoClassifier(checkpoint_paths=paths, device='cuda')
classifier.load_models()
```

## Loading models: SingleVideoClassifier

`SingleVideoClassifier` in `test_already_extracted.py` handles checkpoint
loading and ensemble inference.

```python
from test_already_extracted import SingleVideoClassifier

classifier = SingleVideoClassifier(
    checkpoint_paths=[
        "/workspace/.../models_enhanced/best_ensemble_model_1.pt",
        "/workspace/.../models_enhanced/best_ensemble_model_2.pt",
        "/workspace/.../models_enhanced/best_ensemble_model_3.pt",
        "/workspace/.../models_enhanced/best_ensemble_model_4.pt",
    ],
    device='cuda',
)
classifier.load_models()
```

`load_models()` reads the `model_config` dict stored inside each `.pt` file so
each model is reconstructed with its own architecture settings — no manual
configuration is needed at load time.

## Running inference: predict_standard()

`predict_standard()` runs the feature tensor through every loaded model and
averages the resulting softmax probability vectors:

```python
# features: torch.Tensor of shape [T, 1280]
ensemble_probs = classifier.predict_standard(features)
# ensemble_probs: torch.Tensor of shape [4]  (one probability per class)

predicted_class_idx = ensemble_probs.argmax().item()
print(classifier.class_names[predicted_class_idx])
```

Internally:

```python
def predict_standard(self, features):
    all_model_predictions = []
    with torch.no_grad():
        features_batch = features.unsqueeze(0).to(self.device)  # [1, T, D]
        lengths = torch.tensor([features.shape[0]], device=self.device)
        for model in self.models:
            outputs = model(features_batch, lengths)             # [1, num_classes]
            probs = F.softmax(outputs, dim=1)
            all_model_predictions.append(probs.squeeze(0).cpu())
    # Simple average across all models
    ensemble_probs = torch.stack(all_model_predictions).mean(dim=0)
    return ensemble_probs
```

Class labels are ordered by `category_mapping` index:

| Index | Class |
|---|---|
| 0 | Animation |
| 1 | Flat\_Content |
| 2 | Gaming |
| 3 | Natural\_Content |

<Tip>
  For higher accuracy at the cost of 4× inference time, call
  `classifier.predict_with_tta(features)` instead. TTA runs four temporal
  augmentations (original, reversed, speed-up, slow-down) and averages all
  resulting probability vectors.
</Tip>
